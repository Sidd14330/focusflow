# FocusFlow — Study & Task Planner

FocusFlow is a clean, responsive, browser-based productivity app. It combines a daily task list, priority labels, progress overview, and a simple focus timer in one lightweight interface.

## Features

- Add, complete, filter, and delete tasks
- Set a task priority: high, normal, or low
- Daily progress percentage and task summary
- Focus timer with focus, short-break, and long-break presets
- Short motivational reminders
- Local browser storage — tasks stay on the same browser and device
- Responsive layout for desktop and mobile
- No framework, build step, account, or backend required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

For local development, you can also use the VS Code Live Server extension.

## Data and privacy

Tasks are stored in the browser's `localStorage`. They are not sent to a server. Clearing browser site data may remove saved tasks. Data does not automatically sync between devices.
