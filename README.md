# FocusFlow Ultra

A clean, local-first productivity dashboard with a fresh Apple-inspired glass UI.

## Features
- Task manager with priorities, due dates, search, completion filters, editing and deletion
- Focus Studio with focus and break intervals
- Daily habits with completion tracking and current streaks
- Quick notes
- Weekly activity insights
- Light and dark appearance
- JSON backup export/import
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in a modern browser. No build tools or backend are required.

## Privacy
Tasks, habits, notes and focus totals are stored in this browser's local storage. They are not uploaded to a server. Clearing browser data may erase them. Use Export my data to keep a backup.

## GitHub Pages
Upload the project files to the repository root and enable Pages from the `main` branch, root folder.
